GAMEPLAY & CONTROLS

Main Objective: Play a collection of browser minigames from one hub. Pick a game card, set a unique player name for sync/leaderboards, chase high scores, achievements, streaks, and friends features. Most progress saves on this device; cloud sync is used when online.

Controls: Hub: tap a game card to play; search box filters games; star favorites a game. Help Assistant: tap ? or press F (use F1 inside letter games — Guessword, Hangman, Quiz, Sudoku). Hold Tab to peek who is online. Esc / ☰ Menu pauses most action games and offers Games to return to the hub. Per-game move/shoot keys differ — see Games list below and ask Help “how to play” while inside a game.

Menus: Hub home (My Games grid) has Continue last game, High scores, Leaderboards, Achievements, Players, Friends, Updates, Feedback, Share game, Discord, and ⚙ Settings (look themes, sound, account / player name / player code, Help mascot picker). Inside games: ☰ Menu / Esc for pause, Settings where available (e.g. Fishing Idle ⚙), and Games to return to the hub.
