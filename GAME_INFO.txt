GAMEPLAY & CONTROLS

Main Objective: Play a collection of 32 browser minigames from one hub. Pick a game card, set a unique player name for sync/leaderboards, chase high scores, achievements, streaks, and friends features. Most progress saves on this device; cloud sync is used when online.

Controls: Hub: tap a game card to play; search box filters games; star favorites a game. Help Assistant: tap ? or press F (use F1 inside letter games — Guessword, Hangman, Quiz, Sudoku). Hold Tab to peek who is online. Esc / ☰ Menu pauses most action games and offers Games to return to the hub. Guessword: Daily = one shared Classic 5-letter word; Practice = flex 4/5/6 letters with optional word themes; languages EN/DA/IS; deep link #wordle. Per-game move/shoot keys differ — ask Help “how to play” while inside a game, or see each Game line below.

Menus: Hub home (My Games grid) has Continue last game, High scores, Leaderboards, Achievements, Players, Titles (title + name color pickers), Shop / Coins (full-screen shop stage like Help — balance, daily reward, pickup, Help mascots + Wing Hop + Paper Claim theme skins), Friends, Updates, Feedback, Admin (ICE_DRAGON only — hub-wide master panel: announce, maintenance, players, ban/mute, grants, leaderboard wipe, Discord post, diagnostics; separate from Fishing Idle Admin), Credits (music attribution), Share game, Download app (Windows installer), Discord, and ⚙ Settings (Music/SFX volume, searchable song picker Auto or fixed track, hub look themes, account / player name / player code / transfer / optional password / Discord login, Help mascot picker, notifications). Inside games: press Esc (or ☰ Menu) while playing to open the pause Menu — Sound & music + song search appear there. Settings where available (e.g. Fishing Idle ⚙), and Games to return to the hub. Background music crossfades by screen when Song is Auto.

Hub Coins: Browser localStorage wallet (per player code on this device). Starts at 0. Earn: +5 defeat enemy, +25 win round/level, +50 daily first hub open each day, +25 pickup once every hour, +10 Help AI quest once per day. Spend in Coins shop (Help mascots, Wing Hop skins 250–550, Paper Claim skins 250–550 — Ink, Neon, Honey, Lava, Ice, Pixel, Shadow, Rainbow, Gold, Ocean, Graffiti, Forest, Storm, Candy, Blueprint). Not enough coins shows: You need more coins for this item! Ask Help “how many coins do I have?” to read the saved balance.
